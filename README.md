# Carwash-Inventory-System
  A web-based inventory management system designed for carwash businesses. This system helps track products, monitor stock levels, log services, manage suppliers and categories, and generate reports for inventory usage.

## Features
- User login system
- Dashboard with inventory statistics
- Product management
- Category and supplier management
- Stock-in tracking
- Service management
- Product usage logging
- Low stock, critical stock, and out-of-stock alerts
- Inventory reports with date filters
- PDF export for reports
- Recent usage logs
- Responsive and organized user interface

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- phpMyAdmin

## Installation
1. Download or clone the repository.
2. Move the folder to your XAMPP `htdocs` directory.
3. Start Apache and MySQL in XAMPP.
4. Open phpMyAdmin.
5. Create a database named: carwash_inventory
