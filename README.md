# Carwash-Inventory-Systems
  The system was developed to improve the monitoring, tracking, and management of products, services, stock movements, and operational activities within the carwash establishment.

  The system allows the business owner or administrator to monitor inventory levels, track product usage, manage suppliers and categories, record service-related inventory consumption, and generate inventory-based reports. It also provides forecasting, notification, and audit functionalities to improve inventory decision-making and operational efficiency.

  The system supports role-based access control through Admin and Staff accounts. The Admin has full access to inventory management, reports, forecasting, audit logs, and system configuration, while the Staff account is limited to operational functions such as viewing inventory, logging service usage, and processing service requests. This improves system security and prevents unauthorized inventory manipulation.
  
  The system includes advanced inventory features such as stock alerts, low-stock notifications, inventory forecasting, transaction history tracking, soft deletion with reactivation support, and audit logging. These features help maintain accurate inventory records while providing transparency and accountability for all inventory-related activities.

  In addition, the system was developed using PHP, MySQL, XAMPP, HTML, CSS, JavaScript, and phpMyAdmin as the database management tool. The interface was designed to be responsive, organized, and user-friendly to support both desktop and operational usage within the carwash business environment.
